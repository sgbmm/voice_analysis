# Voice Analysis System (Core Engine)

Асинхронное модульное приложение для комплексного анализа голоса. Архитектура построена на базе паттерна **Layered Architecture** с жесткой валидацией данных на каждом этапе.

## 📂 Структура проекта

```text
voice_analyzer/
│
├── core/                       # Базовые настройки и контракты данных
│   └── schemas.py              # Pydantic-модели (валидация типов)
│
├── ingestion/                  # 1. Уровень захвата и предобработки (VAD, Denoise)
│   └── base.py                 # Абстрактный класс BaseAudioPreprocessor
│
├── features/                   # 2. Уровень извлечения признаков (MFCC, спектрограммы)
│   └── base.py                 # Абстрактный класс BaseFeatureExtractor
│
├── engine/                     # 3. Ядро анализа (Нейросети: ASR, Биометрия, Эмоции)
│   └── base.py                 # Абстрактный класс BaseVoiceEngine
│
├── pipeline.py                 # Асинхронный оркестратор (Параллельный запуск моделей)
├── main.py                     # Точка входа в приложение (Демонстрационный запуск)
└── README.md                   # Документация проекта
```

## 🛠 Технологический стек

* **Язык разработки:** Python 3.10+
* **Асинхронность:** `asyncio` (позволяет параллельно запускать тяжелые инференсы нейросетей)
* **Валидация типов:** `pydantic v2` (строгий контроль форматов аудиоданных и ответов)

## 🚀 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что у вас установлен Pydantic:
```bash
pip install pydantic
```

### 2. Запуск демонстрационного конвейера
В корневой папке проекта выполните команду:
```bash
python main.py
```

## 📐 Архитектурный конвейер (Pipeline)

1. **Ingestion Layer:** Сырое аудио валидируется через `AudioMetadata`, проходит очистку от шумов и тишины (VAD).
2. **Features Layer:** Очищенные байты трансформируются в акустические признаки (вектора/матрицы).
3. **Engine Layer (Параллельный):** Извлеченные признаки одновременно передаются во все активные движки анализа (Распознавание речи, Эмоции, Биометрия) с помощью `asyncio.gather`.

## 🔒 Контракты данных (Pydantic Models)

* `AudioMetadata` — параметры частоты дискретизации, каналов и битности.
* `PreprocessedAudio` — очищенный бинарный поток.
* `AcousticFeatures` — математическая матрица признаков для ИИ-моделей.
* `AnalysisResult` — унифицированный формат ответа (Текст, ID спикера, Эмоция, Confidence).
